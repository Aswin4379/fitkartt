## 1. Executive Summary

The third card of the FitKart Fitness dashboard (`/fitness`) has been upgraded from static "Exercises" to **BodyCare AI** (`/fitness/bodycare`). 

BodyCare AI provides an interactive, clinically safe body discomfort assessment and recovery guidance experience powered dynamically by **Groq AI**. All recommendations—ranging from non-diagnostic explanations and self-care routines to thermal therapy (heat vs. ice), topical precautions, and nutrition—are dynamically generated by the real Groq AI backend. **No hardcoded symptom-to-solution mappings or canned answers are used.**

Quick Start, Custom Routines, the 124-exercise database (`/fitness/library`), active workouts, and tracker workflows remain intact and fully operational.

   - Anatomical regions covered:

2. **Symptom Intake Questionnaire (`components/BodyCare/BodyCareQuestionnaire.jsx`)**
   - Multi-dimensional symptom collection:
     - Discomfort sensation chips (Dull ache, sharp/stabbing, stiffness, burning, throbbing, tingling/numbness, spasms, soreness).
     - Onset timeline (Few hours, 2-3 days, 1-2 weeks, >1 month chronic).
     - Visual numeric severity slider (1 to 10) with dynamic color scale.
     - Acute trauma/injury toggle with contextual detail input.
     - Associated clinical flags (swelling, radiating pain, clicking, morning stiffness, weakness).
     - Freeform user description in their own words.
     - Voluntary consent checkbox for secure assessment persistence.
3. **Structured AI Results (`components/BodyCare/BodyCareResults.jsx`)**
   - Red-Flag Critical Alert Banner (rendered with emergency styling if acute red flags are triggered).
   - Mandatory educational disclaimer and non-diagnostic clarification.
   - Possible explanations (educational considerations, never confirmed diagnosis).
   - Self-Care & Recovery action items.
   - Thermal Therapy (Cold vs. Heat therapy rationale, application duration, skin barrier safety).
   - Movements to Avoid (activities that could aggravate the injured structure).
   - Gentle Mobility & Rehabilitation movements (only when safe; suppressed during acute trauma).
   - Topical pain-relief options with contraindications and patch-test guidelines.
   - Anti-inflammatory and restorative nutrition suggestions.
   - Physician consultation urgency rating (`Routine`, `Prompt`, or `Emergency`).
4. **Follow-Up Conversational Chat (`components/BodyCare/BodyCareFollowUpChat.jsx`)**
   - Multi-turn conversation preserving assessment context (body part, severity, thermal recommendations, red flags).
   - Quick-prompt suggestion chips for recovery, exercise modifications, and sleep ergonomics.
   - Loading state indicators and real-time Groq AI response streaming.
5. **BodyCare Page (`pages/FitnessBodyCare.jsx`)**
   - Orchestrates the full workflow, error boundaries, retry triggers, and past assessment slide-over history drawer.
6. **Fitness Dashboard Card Update (`pages/Fitness.jsx`)**

## 3. Backend AI Engine & Security Architecture

### Backend Services (`backend/src/`)
1. **Groq AI Integration (`controllers/bodyCareController.js`)**
   - Reuses existing backend `GROQ_API_KEY` loaded from `.env`. No API keys are exposed to the client.
   - Implements multi-model failover (`openai/gpt-oss-120b` -> `openai/gpt-oss-20b` -> `qwen/qwen3.8-27b`) with `response_format: { type: "json_object" }`.
   - Strict clinical system prompt guaranteeing educational framing, objective recovery advice, and structured JSON output.
2. **Deterministic Safety Screening Engine (`analyzeRedFlags`)**
   - Runs prior to and alongside AI generation to catch high-risk clinical emergencies:
     - **Cardiovascular:** Chest pain radiating to arm/jaw, dyspnea, heavy pressure.
     - **Neurological / Cauda Equina:** Lower back pain with saddle numbness, bowel/bladder dysfunction, sudden severe leg weakness.
     - **Stroke / Neuro:** Sudden numbness with confusion or loss of motor control.
     - **Acute Trauma / Fracture:** Inability to bear weight with visible deformity.
     - **Vascular / DVT:** Asymmetrical calf swelling, warmth, and redness.
   - If red flags are detected, the system forces `isRedFlag: true`, escalates urgency to `Emergency`, prioritizes emergency care, and strips strenuous exercise recommendations. The AI is prevented from overriding these rules.
3. **Error Handling & Failure Policy**
   - If Groq AI encounters rate limits or upstream network errors, the endpoint returns an explicit `503 Service Unavailable` with a clear user-facing message ("AI guidance is temporarily unavailable").
   - **Zero silent fallbacks to canned medical templates.**
4. **Consent-Gated MongoDB Persistence (`models/BodyCareAssessment.js`)**
   - Assessments are saved to MongoDB **only** when `consentGiven === true` and the user is authenticated (`req.user._id`).
   - Users can review past assessments or delete them with full privacy isolation.

## 4. API Endpoints

| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `POST` | `/api/bodycare/assess` | Generate dynamic recovery guidance via Groq AI with safety triage | Optional (Persists if auth + consent) |
| `POST` | `/api/bodycare/chat` | Contextual multi-turn follow-up conversation | Optional (Updates assessment history if auth) |
| `GET` | `/api/bodycare/history` | Retrieve authenticated user's consented past assessments | Required (JWT) |
| `DELETE` | `/api/bodycare/history/:id` | Delete an assessment record belonging to the user | Required (JWT) |

3. **Follow-Up Context Preservation (Test 4):**
